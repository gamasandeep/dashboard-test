# Brand OS

The shared knowledge layer. Every department reads the relevant folder before it writes.

| Folder | Read by | Files |
|---|---|---|
| `brand-brain/` | everyone | voice-guide, positioning, messaging-bank, tone-rules |
| `signals-seo/` | Search Visibility, Content Engine | keyword-map, serp-rules, ranking-targets, tracking-setup |
| `content/` | Content Engine | content-calendar, brief-templates, hook-bank, seo-checklist |
| `creative/` | Creative Studio | visual-specs, asset-library, video-scripts |
| `social/` | Publishing & Social | channel-playbooks, posting-schedule, hashtag-rules |
| `reputation/` | Reviews & Reputation | gbp-response, review-flow, mentions-rules |
| `conversation/` | Leads & Conversations | faq-library, routing-rules, auto-reply-scripts |
| `reporting/` | Results & ROI | kpi-model, margin-rules, attribution |

Every file is a template with an example brand (a skincare studio). Replace the examples with your own.
