# Brief templates

The Content Engine fills one of these before it drafts.

## Reel (30 seconds)
- Topic, angle, target keyword
- Hook (first 2 seconds, on-screen text)
- 3 beats, one idea each
- Close: soft call to action, no urgency

## Carousel (5–8 slides)
- Slide 1: hook. Slides 2–6: one point each. Last slide: takeaway + soft call to action

## Post (single image / text)
- Hook line, 2–4 short lines, soft call to action

## Blog (800–1,200 words)
- Title with primary keyword, answer first, H2 sections, FAQ, meta description
